### DemoSeeder (src/Continuum.App/Demo/DemoSeeder.cs, namespace Continuum.Demo)

Генератор демо-данных (шаг 8): заполняет БД одной реалистичной прошлой сессией и создаёт настоящий демо-проект на диске. Запускается приложением в режиме --demo до показа окна (вызов подключит интегратор - НЕ трогай App.xaml.cs и CompositionRoot.cs).

Конструктор: (IRepository repository, IClock clock, ILogger<DemoSeeder> logger, string? demoRoot = null). demoRoot null -> %LOCALAPPDATA%\Continuum\DemoProject.

Метод: public Task<bool> SeedAsync(CancellationToken ct = default). Возвращает true, если данные записаны; false - если демо уже засеяно или сбой (идемпотентность, см. ниже). Никогда не бросает.

Алгоритм:
1. Идемпотентность: GetSettingAsync("demo_seeded") == "1" -> вернуть false, ничего не делать. После УСПЕШНОГО засеивания - SetSettingAsync("demo_seeded", "1"). Любой сбой внутри - ключ НЕ ставится, лог + false.
2. Демо-проект на диске (создаётся только если файлов нет, существующие НЕ перезаписываются): DemoProject\README.md (~10 строк осмысленного текста про демо-режим Continuum), DemoProject\src\Program.cs (~15 строк C# с комментарием), DemoProject\src\Main.cs (~10 строк), DemoProject\project.config (3-4 строки ключ=значение).
